# VPS Tools product requirements

The authoritative product requirements document is kept at the repository root as [`vps_tools_prd.md`](../vps_tools_prd.md). It is linked here so documentation readers can find it without treating this page as a second copy.

The root planning set is intentionally separate from the operator documentation:

- [`vps_tools_prd.md`](../vps_tools_prd.md) defines product goals, users, scope, and acceptance criteria.
- [`vps_tools_technical_specification.md`](../vps_tools_technical_specification.md) defines the technical design and service boundaries.
- [`vps_tools_mvp_build_plan.md`](../vps_tools_mvp_build_plan.md) records the phased implementation order.
- [`vps_tools_architecture_decision_records.md`](../vps_tools_architecture_decision_records.md) records important architectural decisions.
- [`vps_tools_data_model_and_initial_schema_spec.md`](../vps_tools_data_model_and_initial_schema_spec.md) defines the initial data model and schema intent.

The current implementation status and release boundary are maintained in the [README](../README.md), [known limitations](KNOWN_LIMITATIONS.md), [production release checklist](production-release.md), and [changelog](../CHANGELOG.md).
